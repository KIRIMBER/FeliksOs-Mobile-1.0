# FeliksOs-Mobile-1.0
FeliksOs Mobile - terminal OS for UserLAnd. 
Made for **fun**, experiments, and learning.  
FeliksOS Mobile is a **toy OS** in your terminal. 
 
It doesn't replace Linux. It **complements** it.  
It's a **sandbox** for those who want to feel like a Kernel.(in future updates) 

---

## 📦 Commands

| Command | What it does |
|---------|--------------|
| `help` | List all commands |
| `version` | FeliksOS version |
| `meow` | Felix meows |
| `cat` | ASCII cat |
| `calc` | Calculator |
| `game` | "Guess the number" game |
| `ceasar` | Caesar cipher |
| `cosmos` | Space animation |
| `market` | FeliksOS Market |
| `clear` | Clear screen |
| `exit` | Exit |

---

## 🛠️ How to run

1. Install **UserLAnd** (Android)
2. Choose **Debian** (Terminal)
3. Install Python:
   ```bash
   sudo apt update && sudo apt install python3 -y
```

4. Copy feliksos.py to your home folder
5. Run:
   ```bash
   python3 feliksos.py
   ```
